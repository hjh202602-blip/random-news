# 🎲 랜덤 뉴스

랜덤 지역, 랜덤 날짜(2017년 이후)에 나온 뉴스 기사의 **제목**과 **링크**를 하나 뽑아 보여주는 웹페이지입니다.

## 사용법

`index.html`을 브라우저로 열고 **기사 뽑기** 버튼을 누르면 됩니다. 설치나 서버, API 키가 필요 없습니다.

## 동작 방식

1. 34개 나라 중 하나와 2017년 1월 1일부터 어제까지 중 하루를 무작위로 고릅니다.
2. 그 나라의 공신력 있는 주요 언론사(통신사, 공영방송, 주요 일간지)에서 그날 나온 기사를 [GDELT DOC API](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/)로 검색합니다.
3. 그중 하나를 골라 지역, 날짜, 제목, 언론사, 원문 링크를 보여줍니다.

언론사 목록은 `index.html`의 `COUNTRIES` 배열에서 고칠 수 있습니다.

## 참고

- GDELT API는 요청을 5초에 한 번으로 제한하기 때문에 결과가 나오기까지 몇 초 걸릴 수 있습니다.
- 이 페이지는 기사 본문이나 이미지를 저장하거나 보여주지 않고, 제목과 원문 링크만 표시합니다. 기사의 저작권은 각 언론사에 있습니다.
